# Vídeos oficiais futuros

Nenhum vídeo foi fornecido ou licenciado nesta prévia. Não há reprodução ou download de vídeo. Ao adicionar vídeo oficial, use WebM/MP4 comprimido, poster, preload adequado, playback silencioso e fallback de imagem para erro, movimento reduzido e dispositivos modestos.

Configure `operationMedia.videoSrc`, `videoType` e `poster` em `lib/media.ts` somente com material real autorizado. O componente `OperationMedia` já implementa reprodução silenciosa perto da viewport, pausa fora dela, poster/fallback em falha e limites para telas pequenas, economia de dados e movimento reduzido. A prévia atual usa a imagem expansiva.
